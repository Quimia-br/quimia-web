# Evidências visuais dos componentes

Capturas dos componentes reais do web com dados ilustrativos, viewport de 1200 px e temas claro/escuro. A prévia usada na captura não é uma página publicada do aplicativo e não faz operações na API real.

Incluem Menu, login/cadastro (Auth completa), Skeleton, ShapeIcon, ProgressBar, FeedbackItem, SendMessage, Chip, PageIndicator, BallonMessage, Toast, SearchBar, ImageContainer, Chart e SwitchButton. ImageEditor tem capturas próprias. Chart mostra linha, barras e donut de evilcharts. SwitchButton mostra o toggle e as aplicações de tema/exibição.

Os arquivos seguem `<componente>-light.png` e `<componente>-dark.png`; as imagens estão incorporadas na PR. Os formulários de login e cadastro demonstram a interface; refresh, sessão, erros e logout são validados pelos testes.
